# 🔎 Repo documentation: wrong claims, duplication and drift

## 🗺 Context

A read of every tracked markdown file outside `CHANGELOG.md`s and the generated adapters: the root
`README.md` and `AGENTS.md`, `docs/` (concepts, guides, `FEATURES.md`, decisions, reviews), every
project `README.md`/`AGENTS.md` including nested ones, `infrastructure/scripts/src/*/README.md` and
`.agents/skills/`. Each claim was checked against the code it describes: `nx.json`, root and project
`package.json`, `.husky/*`, `.github/workflows/*`, `boundaries.ts`, `coreIsolation.ts` and the scripts
source. **Confirmed** means the claim was checked against the file or git history at `commit` (`git
show`, `git log -S`, `grep`). **Likely** means it was reasoned from the code and not checked. Line
numbers are as of `commit`. The working tree had an uncommitted, emptied `.husky/pre-push` at the
time; every hook finding below is against the committed version.
