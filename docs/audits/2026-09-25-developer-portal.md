# 🔎 Developer portal: bugs, duplication and weak code

## 🗺 Context

A static read of `apps/developer-portal`: every non-spec source file under `shared/`, `server/`,
`tools/` and `app/`. A finding marked **Confirmed** was checked against `.report/` or the prerendered
`.output/`; **Likely** was reasoned from the code and not reproduced; the rest were read only. Each
fix comes with a spec that names the failure it pins (`writing-tests` skill). Line numbers are as
of `commit`.
