# 🔎 Architecture follow-ups across the workspace

## 🗺 Context

This audit holds what was left over from a macro architecture review of the whole workspace on
2026-10-21, after the owner's answers removed what was intended. It is not a full read of one
project. Every file it cites was read, and so was each project's `package.json`, README and
`AGENTS.md`, along with the workflows, the hooks and `nx.json`.

**Confirmed** means checked against the cited files, and for a missing gate, a grep showing that
nothing in `.husky/`, `.github/` or `infrastructure/scripts/` runs it. **Likely** means reasoned
about a host or a run that wasn't exercised. Line numbers are as of `commit`.

Several things are deliberately left out:
- `packages/ui`, which is intended boilerplate.
- The design lab.
- The Google Cloud move, which is decided and pending.
- The release flow, which is intended.
- The boundary model's `scope:*` and `type:integration` rework, already under way.
- Work tracked elsewhere:
  - [#280](https://github.com/xfontr/monorepo/issues/280) covers `@monorepo/observability`.
  - [#281](https://github.com/xfontr/monorepo/issues/281) covers docs drift.
  - [#282](https://github.com/xfontr/monorepo/issues/282) covers naming and folder conventions.
  - The [content audit](./2026-10-09-content.md) covers `@monorepo/content`.

   lists come from.

   first, on its own.
